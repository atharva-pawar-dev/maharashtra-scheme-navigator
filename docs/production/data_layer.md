## PostgreSQL 16+ Schema, Migration Engine, S3 Object Storage, and Parity Verification

## 1. Architecture Overview & Data Topology

Maharashtra Scheme Navigator operates a dual-tier persistence architecture:
1. **Local Development & Embedded Offline Mode:** Fast, zero-configuration SQLite databases (`*.sqlite3`) for local testing, unit tests, and air-gapped demo evaluations.
2. **Production High-Concurrency Mode:** Distributed PostgreSQL 16+ with native `JSONB`, `TIMESTAMPTZ`, transaction isolation (`READ COMMITTED`), connection pooling via PgBouncer, and S3-compatible private object storage for citizen documents.

## 3. SQLite to PostgreSQL Migration Engine

The migration utility `scripts/migrate_sqlite_to_postgres.py` performs safe, automated extraction, type translation, and batch loading:
- **Type Casting:** SQLite integer booleans are converted to PostgreSQL `BOOLEAN`, stringified JSON objects to `JSONB`, and ISO timestamps to `TIMESTAMPTZ`.
- **Dry-run Mode:** `--dry-run` outputs full DDL and scans existing databases without database writes.
- **Verification:** Verified by automated suite `tests/test_data_layer_and_storage.py`.

## 4. Private Object Storage Abstraction (`src/scheme_navigator/security/storage.py`)

All document uploads (Aadhaar, income certificates, ration cards, disability certificates) are isolated in private object storage:

### Mandatory Security Controls
1. **Magic-Byte Header Validation:** Prior to persistence, every upload is inspected for genuine magic headers:
   - PDF: `%PDF-` (`application/pdf`)
   - JPEG: `\xff\xd8\xff` (`image/jpeg`)
   - PNG: `\x89PNG\r\n\x1a\n` (`image/png`)
   - Rejects executables, scripts, HTML, SVG, or disguised binary files.
2. **Signed URLs with Strict Expiry:** Direct object access is blocked. Citizens and reviewers access files exclusively via time-limited presigned URLs with a maximum ceiling of **900 seconds (15 minutes)**.
3. **Server-Side Encryption:** Objects written to S3 or compatible storage mandate `ServerSideEncryption: AES256` or `aws:kms`.
4. **Bucket Privacy:** Buckets are provisioned with private ACLs and public access block (`BlockPublicAcls`, `IgnorePublicAcls`, `BlockPublicPolicy`, `RestrictPublicBuckets`).
