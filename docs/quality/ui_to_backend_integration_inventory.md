## 1. Executive Summary & Core Architectural Principle

The user interface is the primary acceptance boundary of **Maharashtra Scheme Navigator**. No backend service, API endpoint, SQLite table, or unit test is deemed complete or valid in isolation without end-to-end integration into the citizen-accessible interface.

This inventory provides an exhaustive, verified map of every user-facing feature across the four core pillars (**Discover**, **Understand**, **Prepare**, **Apply**) and citizen administration. Every row connects an interactive element in the frontend interface (`static/index.html`) to its backend HTTP route (`src/scheme_navigator/api/main.py`), supporting business service, persistent database store, rendered visible DOM outcome, and validating Playwright browser test.

## 3. Statutory & Authenticity Invariants Enforced in UI

1. **Pre-Check Disclaimer Invariant:**
   The Document Auditor interface strictly displays the statutory disclaimer:
   > *"Pre-check of readability, completeness, and consistency; the official department verifies authenticity upon application."*
   The system never renders misleading assertions such as "100% Approved", "Authentic", or "Government Verified" for local algorithmic or OCR checks.

2. **Reactive Profile-Document Invalidation:**
   When a citizen updates a profile attribute (e.g., annual income modified from ₹1,20,000 to ₹1,80,000), any cached document consistency findings (`PROFILE_DOCUMENT_INCOME_MISMATCH`, `INCOME_EXCEEDS_SCHEME_THRESHOLD`) and eligibility determinations are automatically recomputed from the existing extracted data without requiring file re-upload.

3. **Aadhaar Privacy ($D_5$ & Redaction):**
   Aadhaar numbers entered in the UI or detected in OCR text are verified via the Verhoeff $D_5$ checksum algorithm and immediately redacted to `XXXX-XXXX-1234`. Raw 12-digit Aadhaar values are never stored in plain text or rendered unmasked in the UI.

4. **Zero-PII Public Factsheets:**
   The factsheet generator (`openSchemeFactsheet`) produces publicly shareable scheme summaries with official objectives, benefits, required documents, RTS service delivery timelines, and GR citations, strictly stripped of all citizen identity data.
